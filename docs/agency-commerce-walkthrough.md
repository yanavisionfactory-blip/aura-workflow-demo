# Separate agency walkthrough

The isolated commerce showcase demonstrates one Unstoprev weekly marketing review through five stages: request, plan, review, local execution playback and results. It retains the AURA dark theme and uses the supplied completion-page screenshot as the layout reference. The Base44 editor preview required authentication, and external source access required a paid plan; no Base44 application was changed.

Build: `npm run build:commerce`. Publish `dist/showcase/commerce-workflow` to the existing Render static demo service. The main AURA application, authentication, backend and production infrastructure are independent of this entry.

The root opens the walkthrough. `?screen=results` opens the compact completion page, and `?scene=0` through `?scene=4` select a stage. The guide supports play/pause, next, previous, replay and hide. Manual navigation stops autoplay. The browser back button restores the matching stage.

All source reports, product details, accounts, targets and offers are fictional scenario inputs. The four local report processors and packet validation run in the browser. The animated execution stage is explicitly a prepared playback; no vendor API or model call, backend workflow-history entry or client approval is claimed. Receipt IDs represent local source processing. Network connections are blocked by the standalone entry's CSP. The build rejects production API and authentication clients.

The compact results page has four “Open in…” links to separate, illustrative tool workspaces. These show the prepared output in a tool-specific context: Google Search ad assets and preview, Meta primary-text variants and an interactive creative storyboard, Amazon exact-keyword targeting proposal, and Seller Central proposed title/bullets with a detail-page preview. Each workspace has functional navigation to its source performance and report definitions, and a local draft download. A persistent banner identifies simulated tool views; no vendor account or vendor-hosted output is claimed.

Tool deep links use `?tool=google&view=ads`, `?tool=meta&view=creatives`, `?tool=amazon&view=targeting` and `?tool=seller&view=listing`. Evidence IDs route to the correct tool/report, select the matching reporting week and highlight the source row. Inventory evidence opens Seller Central inventory. Navigation is constrained to known tools, views and fixture evidence. The creative product illustration is an authored concept mockup, not a supplied product image or finished production asset.

The results page leads with the main output as an immediately visible report screen: shared product message, inventory priority, three test/draft cards and Seller Central title draft. Its four “Open in…” links remain directly available. Supporting full copy, test designs, implementation checklist, weekly performance, workflow/tool summary, source definitions and next actions are separate dropdowns, all closed initially. Download exports the complete labelled Markdown review. Share copies the public demo results URL. Schedule is an illustrative preview and creates no automation. Connect explains the real-input requirements and does not authorize or alter accounts.

The 30 available units yield approximately 0.70 days of cover. Additional Amazon promotion is held. Website stock is unconfirmed. Website purchases are unavailable without a separate store report; ad-attributed purchases and sales and total Amazon ASIN sales remain separate. All implementation stays pending account-manager approval.

Validation: scenario computation/provenance tests, complete draft rendering, every tool/report view, evidence routing and highlighting, deep-link tests, focused ESLint, standalone build and browser checks of the deployed stages, tool screens and outputs.
